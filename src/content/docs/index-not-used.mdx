## Why LoomiUI

<CardGrid stagger>
	<Card title="Actually framework-agnostic" icon="puzzle">
		Every component is a real custom element built with [Lit](https://lit.dev). Drop
		`<loomi-button>` into React, Vue, Svelte, plain HTML, or a CMS template — no
		wrapper packages, no framework-specific build.
	</Card>
	<Card title="No Tailwind at runtime" icon="pencil">
		Components are *authored* with Tailwind, but it's compiled away at build time and
		inlined into each component's Shadow DOM. Consumers never install Tailwind and
		never fight a global stylesheet.
	</Card>
	<Card title="Theme with one CSS variable" icon="setting">
		Override `--loomi-primary-600` (or any of the 14 palette colors) from your page's
		own CSS and every component re-skins instantly — no rebuild, no config file, no
		Tailwind required on your end.
	</Card>
	<Card title="Install exactly what you need" icon="open-book">
		`npm install @loomi/button` pulls in *only* the button and its direct
		dependencies. Want everything? `npm install @loomi/components` gets the whole
		library in one shot.
	</Card>
	<Card title="Real form participation" icon="approve-check">
		Every form control is form-associated via `ElementInternals` — they submit with a
		native `<form>` like any built-in input, across the shadow boundary.
	</Card>
	<Card title="Built for AI-assisted coding" icon="rocket">
		Ship an [MCP server](/mcp-server/) alongside the library so Claude Code, Cursor,
		and other AI tools can look up real attribute tables instead of guessing at your
		API.
	</Card>
</CardGrid>

## The pitch, in one snippet

A button that ships its own styles, needs no build step on your end, and re-themes
itself when you change a single variable:

```html
<script type="module">
  import "@loomi/button/loomi-button.js";
</script>

<loomi-button color="red" outline radius="full" icon="trash">
  Delete
</loomi-button>

<style>
  /* re-skins every LoomiUI component on the page, not just this button */
  :root {
    --loomi-primary-600: #16a34a;
  }
</style>
```

## What's in the box

44 components across every category a real product needs — forms (`input`, `select`,
`datepicker`, `filepicker`, …), content (`card`, `table`, `chart`, `timeline`, …),
navigation (`tabs`, `pagination`, `dropmenu`, …) and standalone utilities (`modal`,
`notification`, `bell`, …). Install any one on its own, a whole category via
`@loomi/forms` / `@loomi/content` / `@loomi/navigation`, or all of it via
`@loomi/components`.
