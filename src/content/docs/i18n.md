---
title: Internationalization
description: Set a locale, translate built-in component copy, and add languages at runtime.
---

LoomiUI components ship with built-in copy in ten languages, covering placeholders,
validation messages, aria labels, pagination text, and datepicker month and weekday
names. Your own text always wins: attributes like `label`, `placeholder`, and
`ok-button-label` stay the right way to customize a single component. This page covers
using locales in your app.

> Writing or translating a component's built-in strings? That's a contributor task. See
> the [full i18n guide on GitHub](https://github.com/loomidev/loomiui/blob/main/i18n.md).

## Set a locale for the whole page

Call `setLoomiLocale()` once before your components render. Every translatable component
picks it up:

```js
import { setLoomiLocale } from "@loomidev/core";
import "@loomidev/datepicker";
import "@loomidev/filepicker";

setLoomiLocale("fr");
```

## Set a locale on one component

Every translatable component also takes a `locale` attribute, which overrides the
page-wide default for that instance only:

```html
<loomi-datepicker locale="de"></loomi-datepicker>
<loomi-filepicker locale="pt_BR"></loomi-filepicker>
```

## Built-in locales

`en`, `ar`, `de`, `es`, `fr`, `it`, `ml`, `pt_BR`, `tr`, and `zh_CN`. Any locale you
haven't customized falls back to English, so nothing renders blank.

## Add or override copy at runtime

To change wording or add a language without forking LoomiUI, register translations at
runtime with `defineLoomiTranslations()`. You only need to include the keys you want to
change. Everything else keeps its default:

```js
import { defineLoomiTranslations, setLoomiLocale } from "@loomidev/core";

defineLoomiTranslations("hi", {
  datepicker: {
    placeholder: "तारीख़ चुनें",
    monthsShort: ["जन", "फ़र", "मार्च", "अप्रै", "मई", "जून", "जुला", "अग", "सित", "अक्तू", "नव", "दिस"],
    weekdaysShort: ["रवि", "सोम", "मंगल", "बुध", "गुरु", "शुक्र", "शनि"],
  },
  filepicker: {
    placeholderLine1: "फ़ाइल चुनें या यहाँ खींचें",
    placeholderLine2: "%s से %s तक",
  },
});

setLoomiLocale("hi");
```

Datepicker locales can also supply `monthsShort`, `monthsLong`, and `weekdaysShort`
arrays for fully custom month and weekday names.

## Locale is not text direction

Setting a locale changes *which strings and date formats* render. It does **not** flip
layout to right-to-left. Rendering Arabic copy with `locale="ar"` does not make a
component RTL on its own. Right-to-left is a separate, explicit opt-in. See
[RTL Support](/rtl-support/).
