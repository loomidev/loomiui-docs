title: Using with React
description: Add LoomiUI components to a React project — as native custom elements or as full React wrapper components.

LoomiUI ships two packages for React:

| Package | What it gives you |
| --- | --- |
| `@loomidev/react-types` | TypeScript JSX declarations so editors and the compiler understand every `loomi-*` attribute. Types only — no runtime. |
| `@loomidev/react` | Named React components (`<Button />`, `<Select />`, …) with typed props, `on*` event callbacks, and automatic array/object property handling. |

Use `@loomidev/react` for a native React experience. Use `@loomidev/react-types` alone if you prefer to write the raw custom elements but still want full type-checking.

## Option A — React wrapper components

`@loomidev/react` wraps every LoomiUI element in a `forwardRef` component, so you get named exports, typed `on*` callbacks, and automatic DOM property setting for arrays and objects — no `ref` + `useEffect` boilerplate needed.

### 1. Install

```bash
npm install @loomidev/react @loomidev/components lit
```

`react` must already be in your project (it is a peer dependency).

### 2. Import and use

```tsx
import { Button, Select } from "@loomidev/react";

export function CountrySelect({ onChange }: { onChange: (value: string) => void }) {
  return (
    <Select
      data={[
        { label: "Canada", value: "ca" },
        { label: "India", value: "in" },
      ]}
      label-key="label"
      value-key="value"
      onChange={(e) => onChange((e as CustomEvent<{ value: string }>).detail.value)}
    />
  );
}
```

Arrays and objects are set directly on the DOM element (no serialization). Events map to `on*` callback props and are wired via `addEventListener` under the hood, so they work the same way in both React 18 and React 19.

### Available components

Every LoomiUI component has a wrapper. The export name is the tag name without the `loomi-` prefix, in PascalCase:

```
loomi-accordion       → Accordion
loomi-accordion-item  → AccordionItem
loomi-button          → Button
loomi-select          → Select
loomi-data-grid       → DataGrid
...
```

### Forwarding refs

All wrappers use `forwardRef`, so a `ref` gives you the underlying custom element:

```tsx
import { useRef } from "react";
import { Button } from "@loomidev/react";
import type { LoomiButton } from "@loomidev/button";

export function SpinningButton() {
  const ref = useRef<LoomiButton>(null);
  return (
    <Button ref={ref} onClick={() => ref.current?.startSpinner()}>
      Save
    </Button>
  );
}
```

## Option B — Custom elements with JSX types

If you prefer writing the raw `loomi-*` tags, `@loomidev/react-types` adds TypeScript
declarations without adding any runtime code or wrappers.

### 1. Install

```bash
npm install @loomidev/components lit
npm install --save-dev @loomidev/react-types
```

### 2. Configure TypeScript

Add `@loomidev/react-types` to `compilerOptions.types` in your project's `tsconfig.json`:

```json
{
  "compilerOptions": {
    "types": ["@loomidev/react-types"]
  }
}
```

This registers every `loomi-*` tag in the JSX namespace so TypeScript resolves
props, shows autocomplete, and reports type errors without any per-component import.

### 3. Import and use

```tsx
import "@loomidev/components/button";

export function SaveButton() {
  return (
    <loomi-button color="primary" disabled={false}>
      Save
    </loomi-button>
  );
}
```

### Passing arrays and objects (React 18)

React 18 serializes non-primitive values to strings when it sees an unknown element.
Pass a `ref` instead and set array/object properties imperatively in a `useEffect`:

```tsx
import { useEffect, useRef } from "react";
import "@loomidev/components/select";

const options = [
  { label: "Canada", value: "ca" },
  { label: "India", value: "in" },
];

export function CountrySelect() {
  const ref = useRef<HTMLElementTagNameMap["loomi-select"]>(null);

  useEffect(() => {
    if (ref.current) ref.current.data = options;
  }, []);

  return <loomi-select ref={ref} label-key="label" value-key="value" />;
}
```

<loomi-alert type="info" icon="information-circle">
  React 19 understands custom element properties natively — you can pass arrays and
  objects directly as props without a ref.
</loomi-alert>

### Custom events

LoomiUI fires DOM `CustomEvent`s. React does not map these to JSX callback props, so
attach listeners on the element directly:

```tsx
import { useEffect, useRef } from "react";
import "@loomidev/components/select";

export function CountrySelect({ onChange }: { onChange: (value: string) => void }) {
  const ref = useRef<HTMLElementTagNameMap["loomi-select"]>(null);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;

    const handler = (e: Event) => onChange((e as CustomEvent<{ value: string }>).detail.value);
    el.addEventListener("loomi-change", handler);
    return () => el.removeEventListener("loomi-change", handler);
  }, [onChange]);

  return <loomi-select ref={ref} />;
}
```

<loomi-alert type="warning" icon="exclamation-triangle">
  The <a href="/components/data-grid/">Data Grid</a> and other components that accept
  large arrays of records require the <code>ref</code> pattern in React 18 — passing
  arrays as JSX attributes serializes them to <code>"[object Object]"</code>.
</loomi-alert>
